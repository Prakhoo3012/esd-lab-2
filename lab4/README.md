# E-commerce Lab: Amazon Homepage (HTML & CSS)

Build an Amazon-style homepage in `ecommerce_assignment.html` and
`style_ecommerce_assignment.css`. There are 6 sections worth 10 marks each (60 total).

- **Rules and grading:** [best_practices.md](best_practices.md)
- **Colours, fonts and sizes:** [design_spec.md](design_spec.md), including the
  [final expected look](final_expected_look.png) of the page

## Getting started

1. Download this repository (**Code > Download ZIP**, then extract it, or `git clone`).
2. Open the **folder** in VS Code (**File > Open Folder...**).
3. VS Code asks two questions. Answer both so the lab setup can run:
   - **"Do you trust the authors of the files in this folder?"**: choose **Yes, I trust the authors**.
   - **"This workspace has tasks ... that run automatically ... Allow?"**: choose **Allow**.
4. Within a few seconds, **Lab monitor** appears in the status bar (bottom right). If it
   doesn't, run **Terminal > Run Task... > Lab setup: install Lab Activity Monitor**.
5. Work in the two files and save often.

If you chose Restricted Mode or Disallow, the monitor isn't installed and your work can't be
verified. Run the task from step 4 to fix it.

## Lab Activity Monitor: what it records

Opening this folder installs a small VS Code extension, the **Lab Activity Monitor**. It only
watches `ecommerce_assignment.html` and `style_ecommerce_assignment.css`, and it records:

- code pasted from outside your two lab files, including the pasted text and the section it
  went into
- large blocks inserted by autocomplete or snippets
- how many characters you type per minute
- each save (a fingerprint of the file, not a copy)

Everything goes into `lab_activity.log` in this folder. Nothing is sent anywhere, and no other
files, folders or apps are watched.

## No copy-pasting from outside

**Type your code yourself.** Pasting code from outside your two lab files (websites, AI tools,
other files, classmates) is not allowed. It is recorded and reduces your marks. Copying and
pasting **within** your own two lab files, such as duplicating a card you already wrote, is fine.
See [best_practices.md](best_practices.md).

**The monitor stops and uninstalls itself 24 hours after it first runs,** and it won't
reinstall after that. To remove it sooner, uninstall **Lab Activity Monitor** from the
Extensions view.

## Submitting

1. Save both files in VS Code.
2. Submit the **whole folder**, including `lab_activity.log` (zip it).
3. Do not edit, delete or copy `lab_activity.log`. A missing or edited log, or files changed
   outside VS Code, will be reviewed by your instructor.
